# VR prompt artwork

Original Oculus/Vive PNGs by Nicolae (Xelu) Berbece / Those Awesome Guys.
Official pack: https://thoseawesomeguys.com/prompts/
Downloaded from https://github.com/DJLink/Xelu_Free_Controller-Key_Prompts
Git tree: `e71969dc7ac7f35ed7ad47d38b0524d099d4aa61` (paths `Others/VR/Oculus` and `Others/VR/Vive`).
Original CC0 licence and readme are preserved in `Source/`.

The atlas generator crops/rescales these PNGs and adds left/right labels.
At runtime, Touch A/B/X/Y use the existing game font's matching letter-button
glyphs when available, preserving the native UI appearance; the atlas remains
the fallback for fonts without those glyphs and for other physical controls.
All other cells are original, neutral labelled fallback artwork generated by
`Tools/GenerateVRPromptAtlas.py`; those additions are also dedicated to CC0.
Index/WMR/generic rows are neutral symbols, not official manufacturer artwork.
No runtime download or proprietary SDK artwork is required.
