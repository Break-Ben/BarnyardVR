# VR prompt artwork

Original Oculus/Vive and Xbox stick PNGs by Nicolae (Xelu) Berbece / Those Awesome Guys.
Official pack: https://thoseawesomeguys.com/prompts/
Downloaded from https://github.com/DJLink/Xelu_Free_Controller-Key_Prompts
Git tree: `e71969dc7ac7f35ed7ad47d38b0524d099d4aa61` (paths `Others/VR/Oculus`, `Others/VR/Vive`, and `Xbox Series/XboxSeriesX_Left_Stick.png`).
Original CC0 licence and readme are preserved in `Source/`.

The atlas generator crops/rescales these PNGs without adding labels beneath the artwork.
OpenXR prompts use this supplemental atlas, including Touch face buttons;
the game's existing native GameCube/PS2 glyphs remain unchanged. A separate
Xbox stick glyph is used for the honey-collection gamepad prompt only.
All other cells are original, neutral labelled fallback artwork generated by
`Tools/GenerateVRPromptAtlas.py`; those additions are also dedicated to CC0.
Index/WMR/generic rows are neutral symbols, not official manufacturer artwork.
No runtime download or proprietary SDK artwork is required.
